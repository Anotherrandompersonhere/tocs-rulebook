# TOCS — Tactical Operations Combat System

A realistic, medium-speed tabletop combat system for d20-based tactical/military campaigns. Built for GM-hosted play — the rules are a baseline, not a complete ruleset; adjudication of anything not explicitly covered is left to the table running it.

## Contents

- [`TOCS-rulebook.md`](./TOCS-rulebook.md) — the full ruleset (Health, Environment/Spotting, Gunplay, Turn Economy, Armor, Stats, Medical, Explosives, CQC, Vehicles).
- [`TOCS-worked-examples.md`](./TOCS-worked-examples.md) — a blank character sheet template plus a full sample character with worked examples for every major subsystem.

## Notes

- This is a snapshot of an actively playtested homebrew system. Numbers may not be perfectly balanced for every table — see the Creator Note at the top of the rulebook.
- Feel free to fork and adjust for your own campaign's era, tone, and desired lethality.
